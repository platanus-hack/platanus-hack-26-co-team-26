# Privacy boundaries

Raw location history is encrypted and local by default. Users control tracking, background tracking, history deletion, emergency sharing, and trusted contacts. A shared emergency snapshot contains only the latest usable position or clearly labeled estimate, accuracy, timestamps, recent movement evidence, battery, and transport provenance.

Public projections expose affected regions, anonymous counts, resource needs, and verified progress only. Family projections follow consented granularity. Responder projections require role and organization authorization; any backend response containing PII must create an audit entry before returning data.

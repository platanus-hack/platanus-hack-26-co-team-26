# Operación offline

**Estado: PARCIAL.** Funcionan sin Internet la captura de sensores, el procesamiento local PPG, la evidencia de movimiento, la estimación local de ubicación y el flujo de autenticación demo. El backend, alertas sísmicas reales, sincronización y envío remoto necesitan red.

No se debe ocultar la falta de conexión: cada pantalla debe indicar si el dato es local, antiguo, estimado o de demostración.

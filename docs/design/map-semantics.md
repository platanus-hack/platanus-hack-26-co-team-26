# Map semantics

Stable source/layer IDs include `base-map`, `terrain`, `buildings-3d`, `my-location`, `my-location-accuracy`, `trusted-contacts`, `emergency-devices`, `device-clusters`, `device-accuracy`, `motion-events`, `sos-events`, `frequent-places`, `location-history`, `historical-estimates`, `search-areas`, `incident-zones`, `rescue-units`, `physiological-reports`, and `mesh-links`.

Points represent device evidence; LineStrings represent trajectories or explicitly labeled network links; Polygons/MultiPolygons represent search or incident areas. Mesh paths never imply physical movement. Ordinary GPS never implies victim depth or floor.
